# ADR-0052　全量措辞去夜间化（「夜间 / 每夜 / 当夜 / 晨间 / 早晨 / 白天」→ 时间中性词）

状态：**Accepted**（2026-09-26，人类 chat：「做「全量措辞」扫」）　日期：2026-09-26　Supersedes：—　Superseded by：—
关联：**ADR-0050** D1（本 ADR 把它从「6 个章节」扩到「全部现行正文」）、**ADR-0051**（改名；本 ADR 是其**措辞**续篇）、**ADR-0039 D5**（README 冻结段例外）、**ADR-0021 / ADR-0030**（MEMORY.md 例外）、**ADR-0031**（任务卡正文只读）、**ADR-0029 D4**（回退清单正文不改）、**ADR-0028**（`guard` 锁）

## 背景（为什么现在要决定）

ADR-0050 只把章程 §11.1 / §11.2 / §11.3 / §11.4 / §11.9 / §11.11 A2 与手册 §4.1 / §4.1.a / §4.1.c / §6 的措辞时间中性化；ADR-0051 只改了**路径 / 目录 / 锁名 / 分支名**。结果：**现行正文里仍有大量**「夜间 / 每夜 / 当夜 / 晨间」以及**同族的时间框架词**（「早晨流程」「人类醒来」「白天会话」「深夜更正」）—— 例如章程 §5「白盒测试的**夜间**硬性要求」、§7「**晨间**报告」、§8「人类的**早晨**流程」、§9「什么工作**不该**放到**夜间**」、§13「当前**夜间**工作单」。读者（尤其开源后的外部读者）仍会以为自动化只能在夜里跑，或以为这是「夜间 vs 白天」的两班制。人类 2026-09-26 指示「做「全量措辞」扫」。

## 决策（一句话）

**把「现行正文」里的夜间族措辞全量换成时间中性词**（不止 `夜间 / 每夜 / 当夜 / 晨间 / 整夜`，还包括同族的 `早晨 / 早上 / 醒来 / 白天 / 深夜`）；**只读 / 只追加的历史记录一律不动**。

## 决策细化

| # | 内容 |

## 考虑过的选项（至少 2 个，含被否理由）

| # | 选项 | 结论 | 理由 |
|---|---|---|---|
| 1 | 不做（靠 ADR-0050 的「历史命名」声明覆盖） | ❌ 否决 | 读者仍会看到「## 9. 什么工作不该放到夜间」这类**标题**，一句声明挡不住 |
| 2 | **全量扫现行正文（本 ADR）** | ✅ **采纳** | 目标达成；只读 / 只追加的历史记录不动 |
| 3 | 连历史记录一起扫 | ❌ 否决 | 违反「ADR 只增不改 / LEDGER 只追加 / 任务卡正文只读」 |
| 4 | 只扫 ADR-0050 点名的 4 个词（`夜间 / 每夜 / 当夜 / 晨间`） | ❌ 否决 | 会漏掉「人类的**早晨**流程」「人类**醒来**看到」「**白天**会话」等同族措辞，读者仍读到「夜间 vs 白天」的两班制框架 |
| 5 | 连数字预算（`05:00` / `23:30`）一起改 | ❌ 本次否决 | 那是**规则**不是措辞；改它需要单独裁决 |
