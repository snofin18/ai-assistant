# ADR-0078　不设立 `scripts/` 顶层目录（PL-023 作废收口）

状态：**Accepted**（2026-10-06，按用户 2026-10-06 裁决「PL-023 作废」）　日期：2026-10-06　Supersedes：—　Superseded by：—
关联：ADR-0069、ADR-0029、ADR-0054、`docs/adr/top-level-directories.md`、`docs/PARKING_LOT.md` PL-023 / PL-057、`docs/automation-charter.md` §11

## 背景（为什么现在要决定）

`docs/adr/top-level-directories.md` 的变更规则第 3 条写着「`scripts/` 尚未获授权；是否把它与 `tools/`
合并或单列，**由 PL-023 的后续 ADR 决定**」，ADR-0069 的 D8 / 风险表也把这一点记成「PL-023 仍需单独裁决」。
但 PL-023 的两半早已失去对象：

- **② `scripts/` + `scripts/nightly-run.ps1`**：2026-09-24 已作废 —— ADR-0029 把夜间自动化主方案换成
  Codex 原生 scheduled tasks（ADR-0018 降级为已被取代的回退方案），其影响表明确写「**不创建**」。
- **① `docs/nightly/logs/` 是否入库**：目录不存在，且 ADR-0054 规定自动化留痕**先落 PR 再自删** ——
  轮次日志不再以该目录为落点（其残留引用归 PL-057）。

于是只剩一个悬而未决的措辞冲突：**白名单附表把 `scripts/` 的处置指向了一个已经作废的条目**。
按 ADR-0069（「新增目录必须先有 Accepted ADR 或 ADR-0069 正式修订」），本 ADR 就是那次正式裁决。

## 决策（一句话）

**不设立 `scripts/` 顶层目录；脚本类内容一律归已获授权的 `tools/`（TASK-228）；`docs/nightly/logs/`
同样不设立 —— PL-023 作废，其指向关系由本 ADR 取代。**

## 决策细化

| # | 内容 |
|---|---|
| **D1** | `scripts/` **不进入** `docs/adr/top-level-directories.md` 白名单，也**不允许**在仓库根新建该目录；`hygiene/unregistered-top-level-directory`（ADR-0069，Error 级）会照常拒绝它。 |
| **D2** | 脚本类内容的落点 = `tools/`（白名单已登记，授权 = TASK-228，定位「独立开发辅助工具，不进入产品运行路径」）。再没有第二个同义目录。 |
| **D3** | `docs/nightly/logs/` 也不设立：自动化轮次留痕走 **ADR-0054**（先开 docs-only PR 落地，再自删自动化）。章程 §11 里 3 处把该目录当日志落点的表述仍归 **PL-057** 校准，本 ADR 不代改章程正文。 |
| **D4** | **修订指向关系**（不改 ADR-0069 的实质结论）：ADR-0069 D8 的「未来若需要 `scripts/`，必须由新 ADR 明确边界后再加入」**继续有效**；本 ADR 只是裁定**当下不设立**，并取代「由 PL-023 的后续 ADR 决定」这一指向。附录规则第 3 条同步改写为指向本 ADR。 |
| **D5** | **若将来真需要 `scripts/`**：那时再开**新** ADR（或修订本 ADR）说明它与 `tools/` / `xtask/` 的边界，并按 ADR-0069 规则第 1/2 条登记白名单。**不复用 PL-023**（与该条 2026-09-24 的处置一致）。 |
| **D6** | 本 ADR 不改任何代码、不新增依赖、不改 `xtask` 规则判据；`PL-023` 在 `docs/PARKING_LOT.md` 追加**作废**行（不改写原行）。 |

## 考虑过的选项（至少 2 个，含被否理由）

| # | 选项 | 结论 | 理由 |
|---|---|---|---|
| 1 | 设立 `scripts/`，把一次性脚本从 `tools/` 分出来 | ❌ 否决 | `tools/` 的定位（独立开发辅助工具、不进产品运行路径）已经完全覆盖脚本用途；再开 `scripts/` 只会产生两个语义重叠的顶层目录，而 PL-023 的两半都已经没有需要它的对象。 |
| 2 | 什么都不做，让附表规则第 3 条继续指向 PL-023 | ❌ 否决 | 该条已被 TASK-239 复核判为「已被后续 ADR/卡取代，无需再做」—— 让现行契约指向一个作废条目，正是本项目最忌讳的「静默漂移」。 |
| 3 | **用新 ADR 裁定不设立 `scripts/`，并把附表指向改到本 ADR（本 ADR）** | ✅ **采纳** | 走 ADR-0069 指定的正式机制；ADR-0069 的「不预授权」结论保持不变，只改指向；`tools/` 继续作为唯一脚本落点。 |

- `docs/adr/README.md`：登记本 ADR；ADR-0069 行的一句摘要补上「`scripts/` 由 ADR-0078 裁定不设立」。

- **不改** ADR-0069 / ADR-0071 的正文（ADR 只增不改）；本 ADR 的关联与 D4 已显式取代其指向。
