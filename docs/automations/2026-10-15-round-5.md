## ④ 实现

新增 `crates/ipc/tests/windows_transport_failure_contract.rs`（6 个公开 API
契约测试）：

1. 非法管道名（空、空白、路径分隔符、超长）在 client / server 构造期都返回
   `Serialization`。
2. 未连接 / 已关闭句柄上的 `send` / `recv` / `accept` / `peer_process_id`
   全部显式失败。
3. `accept` 无客户端时按 50 ms 超时返回 `Timeout`，随后仍可安全关闭服务端。
4. `recv` 超时触发 overlapped read 取消；服务端保持在连接上发送后，客户端仍可
   收到消息，证明取消 / 回收后句柄可继续使用。
5. 不读对端时，发送超过 64 KiB 管道缓冲的 4 MiB 消息会按 50 ms 超时返回
   `Timeout`，而不是挂死或假装成功。
6. 不存在的 PID 查询镜像路径返回 `PeerIdentityUnavailable`。

生产源码零改动；未加依赖 / schema / lint / CI 改动。
