## 2. 环境探测与工具偏差（如实记）

- 首次探测按 prompt 要求走 `shell: "powershell"`：`Get-Command cargo,rg,gh` + `$PSVersionTable`
  **零输出挂起**（等待约 2 分钟）。随后依次实测 `pwsh`、`login:false` + `tty:true`、
  裸 `echo`（默认 bash）**四种调用全部无输出**；`tty:true` 只回了 4 字节终端控制序列
  `\x1b[?9001h\x1b[?1004h`。→ 本机本次运行的 **PowerShell / bash 通道不可用**。
- 实测 `shell: "cmd"` **正常**（`cmd /c echo` 0.0 s 返回；`where cargo,rg,gh,pwsh` 全部解析到
  可执行文件）。故本 run 的**所有** `exec_command` 改用 `shell: "cmd"`，命令一律
  `chcp 65001>nul & …` 以 UTF-8 输出；同 `cmd` 不解析含 `|` / `^` / `>` 的引号参数
  （会整段报「不是内部或外部命令」），故所有含中文 / 正则的命令都改为 `rg -f <UTF-8 模式文件>`。
- 后果与边界：`pwsh -NoProfile -File` 同样挂起，因此本 run **没有**执行任何 `.ps1` 脚本
  （本卡的验收命令里也没有 `.ps1`；Paint / adapter 的 `.ps1` 探针与 `validate_adapter_pack.py`
  不在本卡范围）。
