## ② 本轮任务

`TASK-253` / `PL-073`：任务卡 `- 状态：` 行是正文区唯一可写例外。

原矛盾：ADR-0031 把状态唯一落点放在分界线以上的 `- 状态：` 行，同时又把分界线以上定义为
Implementer 只读；Implementer 完成卡后无法按规则更新状态。ADR-0041 解决了计划文件同类问题，
但没有定义任务卡状态行。

本轮裁决：

1. 唯一例外 = `- 状态：` 行。
2. 只允许按真实状态更新，且必须与状态提交同批。
3. 其他正文行仍只读；`plans/*` 不得新增状态列。
4. `card-check` 未来接入 git diff 时必须只排除唯一状态行。
