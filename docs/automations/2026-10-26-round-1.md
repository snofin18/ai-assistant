## 1. 为什么这是 human round

ADR-0089 D4/D5 规定，`N_auto` 从最近一个显式 `机制=human` 轮次重新计算；仅凭聊天中
“人工任务已重置”而没有轮次文件，后续 agent 无法从仓库事实源复算。本文件就是该 reset
的正式留痕，不把 automation 轮次误标为 human。

在新命令加入后、本文件落地前，`cargo run -p xtask -- automation-rounds --run-date 2026-10-26`
的真实输出为：

```text

existing_rounds_for_run_date=0
next_round=1
latest_human=docs/automations/2026-10-14-round-2.md
n_auto=44
missing_after_latest_human=0

```

因此本次人工会话开始前的严格口径是 `N_auto=44`。本文件落地后，最近 human reset
变为本文件，`N_auto` 从 0 重新累计。
