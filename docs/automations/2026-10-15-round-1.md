## 实现

新增 `crates/replay/tests/provider_contract.rs`（公开 API 契约测试，11 个用例）：

1. `ExactNameAndRole` 命中唯一记录节点（name + role 同时相等）。
2. 同名但 role 不同 → `TargetNotFound`（证明 role 半边真的参与匹配，不退化成
   `ExactName`）。
3. name 为空 → `ToolInvalidArgs`（空名会匹配一切，属配置错误）。
4. 取值变体不是 `SelectorValue::ExactNameAndRole` → `CapabilityMissing`（不静默降级）。
5. 两个同名同 role 节点 → `TargetAmbiguous`（不靠先到先得）。
6. `wait_for` → `CapabilityMissing`（v0 未录制该能力，不得伪装成超时）。
7. `resolve_element` 传入不匹配的窗口句柄 → `TargetNotFound`。
8. `RoleAndParent` 自引用 → 有界深度上限 → `ToolInvalidArgs`（不是无限递归）。
9. kind / value 不匹配 → 回退分支匹配不到任何节点 → `TargetNotFound`。
10. 结构非法的 `TargetDescriptor`（空白 `descriptor_version`）→ `ToolInvalidArgs`。
11. 记录内的整窗指纹逐字符回放（verify / undo 要拿到的就是录下来的值，不是重算值）。

改动规模：新增测试文件 262 行；**生产源码零改动**，无新依赖、无 schema / lint / CI 改动。
