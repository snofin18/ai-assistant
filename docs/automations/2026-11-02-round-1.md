## 实现

- Tauri `event_bridge.rs` 复用 `CorePipeTransport::subscribe`，单实例后台泵。
- bridge payload 分为 `event` / `failure`，前端 strict zod 校验后进入 App。
- App 显示 `step_approval_requested` 审批卡和脱敏字段 diff；approve/deny 只发送既有
  `UiCommand`。
- React StrictMode 第二次启动的 `ui_event_stream_already_running` 视为复用已运行泵，
  重新挂 listener 而不是报断连。
- 未修改 `UiEvent` / Tool / protocol / DB schema，未新增依赖，未启动真实浏览器。
